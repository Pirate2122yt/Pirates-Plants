# Pirates-Plants
A repo connecting (eventually) to my personal plant database. I will keep everything updated through here.

This is a self hosted Plant Database made by me!
It will connect to two websites (when finished) which are Plants.Pirate2122.com and Carnivores.Pirate2122.com

## Features
The features for this site and repo will be including (but not limited to):
* Photos
* Dates
* Plant Notes and Info
* Plant Care Information 
* Optional Times
* GitHub Based Development 
* Separated spots for Carnivorous and Normal Plants
* Mobile Friendly Design 

## Hosting 
The website is self-hosted using a dedicated Proxmox LXC and is served through Cloudflare.
GitHub is used as the source repository and for version control.
